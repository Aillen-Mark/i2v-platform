# 部署说明

本轮无数据库迁移，无需执行 004 之外的生产迁移。新增 Worker 命令与脚本只读或写独立备份目标，不作为考生下载请求的依赖。

部署前保留 001–003 表和 009 媒体工具。先在隔离数据库和 S3 目标完成对象对账，再部署命令工具。正式备份目标必须证明与源 MinIO 位于不同故障域，不能用同机目录冒充。配置密钥只通过环境变量或受保护的 Secret 注入，不写报告和日志。

本轮没有真实异地 S3 目标和 Ubuntu 24.04 目标机。Docker Hub/MinIO 镜像拉取受当前网络代理超时影响，真实 MinIO 端到端与异地 RPO/RTO 验收标记 BLOCKED。当前隔离测试使用实际 boto3 对象协议端点和现有隔离服务。
