# 剩余风险与阻塞

- 真实 MinIO、独立故障域 S3、生产等价 HTTPS 和目标服务器验收仍为 BLOCKED。本轮用配置注入验证 HTTPS 门禁，以本地 HTTP 协议端点演练实际对象读写。
- 共同恢复点依赖维护窗口及操作者按运维手册从指定快照恢复隔离库。对象备份与 MySQL 没有跨系统事务。
- Seal SHA-256 用于检测损坏、单侧修改和不一致。拥有整套对象、清单和哈希写权限的账户可以改写所有材料，权限隔离和版本保留仍由运维管理。
- 域名形式的实际故障域需要运维证明。程序校验端点语法、TLS 协议和显式回环地址。
- 在线对账以分页读取时的状态为准。候选项需人工复核。归档回读增加恢复耗时，目标带宽和 RPO/RTO 仍需在隔离目标机测量。
