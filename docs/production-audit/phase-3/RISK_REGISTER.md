# 风险清单

| 风险 | 本轮处置 |
| --- | --- |
| 短片、坏片字节完整却进入成功 | 校验真实流时长和完整解码；恢复时复查旧版检查点。 |
| 静音源缺流 | 补静音 AAC，损坏的已有音轨仍需报错。 |
| Worker 死亡留下编码进程和文件 | 限时退出、按世代隔离临时文件、扫描过期目录。 |
| 已有成功历史作品可能不符合新规则 | 历史终态保持原样。 |
| 资源不足及生产性能 | 按文件上限和剩余磁盘进行本地限制。目标机容量和持续压力由后续 Issue 验收。 |
| 上游结果过期或不可恢复 | 保留上游 ID 和现有人工核对流程。 |
| 引擎分辨率信息来自当期引擎记录 | 已创建任务没有独立分辨率快照；记录适用档位和允许范围，并保留历史缺省规则。 |

| 当前 HTTP 交付可能缺少可靠传输边界 | HTTP/1.x 仅连接关闭的响应会被拒绝并保留原任务。实际 MiniMax CDN 响应需联调确认。 |
| 临时盘瞬时并发 | 100 MB 下载和 30 MB 成片是单任务上限，256 MiB 是检查时的剩余空间。多个执行者可能同时看见足够空间。当前用单生成进程控制初始预算。 |
| 磁盘孤儿缺少可验证执行记录 | 清理保留无法与数据库对应的目录，由运维核查。清理在持有同一专用本机目录的恢复进程运行。 |
| S3 请求已写出后失去租约 | 本地 SDK 停止后续读，已在途的字节可能到达旧世代对象。MySQL 不接受旧租约成功回写，对象键隔离后续世代。 |
| 审计操作人使用共享 OS 工号 | 记录实际 OS 账户和案件编号。个人级追责取决于个人登录与外部证据。 |
