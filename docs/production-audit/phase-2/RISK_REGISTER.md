# 风险清单

| 风险 | 处置 |
|---|---|
| POST 已发生而返回 ID 未落库 | 保留未知状态与本地时间线，核对后附加上游 ID。 |
| 旧版执行者运行时绕过租约 | 部署必须停止旧的真实 Worker、扫描器与派发，禁止混跑跨代消费者。 |
| 旧 Work 无可靠提交证据 | 不做批量补投或退额，首次恢复时隔离有歧义的记录。 |
| Redis 不可用 | 认证、调度与限流可能短时中断；恢复后依赖数据库重新派发。 |
| 上游已成功而对象保存未完成 | 续查或接续上传，无法恢复时人工核对。MinIO 持续对账、备份和完整媒体验真分别由 008/009 覆盖。 |
| 单机或外部供应商不可用 | 租约不是跨故障域高可用，也不能提供端到端 exactly-once。 |
